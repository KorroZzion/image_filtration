# Изображения экспериментов с КТ-границами

Это настоящие файлы изображений, скопированные из файловой системы облачной среды
для просмотра и скачивания через GitHub. Каждый файл декодирован; SHA-256 копии
совпадает с SHA-256 оригинала. Оригинальные файлы сохранены на прежних местах.

Чтобы скачать отдельное изображение, откройте его и выберите **Download raw file**.
Чтобы скачать всю ветку, выберите **Code → Download ZIP**. Ссылки sandbox и интерфейс
артефактов Codex для этого не требуются.

## Полный пофайловый список

[Каталог всех изображений](IMAGE_INVENTORY.md) содержит полный путь в среде, размер
в байтах, формат и разрешение каждого файла. Также доступны
[CSV](image_inventory.csv), [JSON](image_inventory.json) и
[контрольные суммы](SHA256SUMS.txt). Пути в CSV относительны корню репозитория
в колонке repository_path; исходные и конечные абсолютные пути сохранены отдельно.

## Что находится в каталогах

- `experiments/final` — основное сравнение методов и наложения для блока из 25 срезов.
- `experiments/hybrid` — диагностические маски гибридного опыта на 501 срезе;
  метод дал пропуски каналов и не принят как готовый поиск всех поверхностей.
- `experiments/tracking` — в том числе неудачный перенос всей маски с дрейфом границы.
- Остальные подкаталоги `experiments` — промежуточные опыты, сохранённые без изменения.
- `onboarding/three_detectors` — изображения первоначальной проверки трёх детекторов.
- `onboarding/legacy_v4` — более ранняя проверка на синтетическом томе.
- `fixtures/synthetic_smoke` — 1019 синтетических TIFF для ранней проверки запуска;
  это не реальные КТ-срезы детали. Они совпадают по содержимому, но сохранены
  отдельными файлами с исходными именами.

Оригинальные 501 TIFF в `CT_Test` уже находились в репозитории и повторно сюда не
копировались. Символические ссылки на них в рабочих каталогах также исключены.
Пути с Windows-подобным компонентом `D:` заменены короткими переносимыми каталогами;
содержимое изображений не перекодировалось и не менялось.

Полученные контуры — результаты экспериментов. Единой надёжной автоматической
инициализации для всей выборки и подтверждённой метрологической точности пока нет.
