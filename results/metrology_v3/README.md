# Сравнение методов определения поверхностей КТ — 28 октября 2026

**Пропуски границ на переходном сечении полностью не устранены.** Лучшее улучшение локализации получено модельной подгонкой профиля на фантоме. На реальной КТ некоторые профили и стенки остаются неоднозначными; эти результаты пока нельзя считать метрологически подтверждённой границей.

[Поиск литературы, проверенные источники и ограничения доступа](../../experiments/CT_SURFACE_LITERATURE.md). Прямой поиск/полные тексты Crossref, NIST, IEEE, Springer, arXiv и PLOS блокируются шлюзом HTTP 403; использованы доступные открытые реализации и их библиография.

## Что применено и что получилось

| Метод | Результат и ограничение |
|---|---|
| 3D Farid–Simoncelli + адаптивный Canny | Сравнён на тех же исходных масках. Пропуски стенок сохраняются; на фантоме выигрыша относительно Gaussian не получено. |
| Локальная region-scalable energy + 3D TV, масштабы 6 и 12 | Может менять связность. Некоторые верхние границы добавились, но часть слабых стенок по-прежнему теряется; заметна зависимость от масштаба. |
| Начальная разметка по локальному контрасту + локальная энергия, масштабы 3 и 6 | Даёт больше кандидатов, но также ложные структуры в каналах и материале. Не принята как итоговая сегментация. |
| Гессиан + подгонка двух размытых поверхностей | Консервативные предложения новых тонких стенок по измеренному контрасту. Не восстанавливают все пропуски; остаются экспериментальными. |
| Подгонка PSF-профиля исходной КТ вдоль 3D-нормали | Лучший результат локализации на фантоме; на реальной КТ ограничивает уточнение по качеству модели. Сохраняющий топологию вариант не создаёт пропущенные каналы. |

В отличие от сглаживания готовой сетки, PSF-подгонка использует интенсивность исходной КТ. Проверяются одиночный скачок и пара поверхностей тонкой стенки, линейный фон, остаток и идентифицируемость. Неподтверждённые точки остаются исходными; опасные для граней сдвиги уменьшаются и отмечаются как неподтверждённые.

## Проверка координат на известной геометрии

Одинаковые начальные маски сферы с наклонным каналом, неоднородной яркостью и тремя независимыми добавками шума. В таблице ошибка относительно аналитических поверхностей; генератор сначала вокселизует геометрию и размывает её. Значения относятся только к этому фантому.

| Метод | P95 ошибки, vox, диапазон трёх опытов |
|---|---:|
| Gaussian + 3D Canny/градиент | 0.355–0.356 |
| Farid + 3D Canny/градиент | 0.360–0.360 |
| Модель профиля PSF | 0.264–0.267 |

На 80 профилях тонких стенок: P95 модели одиночной границы = 1.481 vox, двух поверхностей = 0.177 vox. При очень тонкой стенке амплитуда, ширина и PSF связаны; неоднозначные пары не принимаются автоматически.

## На реальных данных: качество подгонки, не точность

**75 срезов** в блоках 500–524, 738–762, 976–1000 плюс реальный контекст до восьми срезов. Фильтры не получают искусственно повторённых TIFF. Маска в контексте — начальная геометрическая оценка, её происхождение описано в коде.

| Блок | Вариант | Вершины с принятой подгонкой | P95 смещения, vox | Геометрия сетки |
|---|---|---:|---:|---|
| 500–524 | preserved_topology | 45.5% | 0.732 | прошла |
| 738–762 | preserved_topology | 51.5% | 0.930 | прошла |
| 738–762 | local_rsf_6 | 56.3% | 1.148 | прошла |
| 738–762 | profile_wall_proposals | 54.8% | 1.110 | отклонена |
| 976–1000 | preserved_topology | 57.1% | 0.572 | прошла |

Проценты выше — прохождение выбранных критериев модели; их нельзя сравнивать с долей рёбер Canny как оценки точности. Смещение поверхности тоже не равно ошибке.

## Геометрия, файлы и единицы

Сохранены PNG, численные маски/координаты NPZ и пересечения с исходными срезами CSV.GZ. PLY распространяются только для моделей, прошедших проверку конечности координат, индексов, вырождения/переворота граней, манифолдности рёбер и открытых краёв только на торцах. Глобальная проверка пересечений удалённых треугольников не выполнена. Диагностические NPZ могут содержать отклонённую сетку; её статус есть в metrics.json.

`surface_voxels.ply`: X/Y в координатах исходного изображения, Z=0 у первого среза блока. `surface_mm.ply`: миллиметры, X/Y от пикселя (0,0), Z=0 на img_0500. Кубический воксель 75,4 мкм подтверждён пользователем; независимая калибровка сканера здесь не проверялась. Фрагменты открыты на торцах и не являются полной замкнутой моделью детали.

## Что необходимо для проверки требуемой точности

`lopatka.stl` не найден в доступных файлах и Git-истории. Без него или иной контрольной геометрии точность на реальной детали не измерена. После получения модели нужны проверка единиц, жёсткое совмещение, отдельная оценка наружных и внутренних поверхностей с P95/максимумом расхождения. Ручная модель сама может иметь погрешность. Воксельный шаг известен, но требуемый допуск пока не задан.

## Воспроизведение

Из корня репозитория с зависимостями experiments/requirements.txt. Каталоги вывода должны быть новыми.

```bash
python -m unittest discover -s experiments -p "test_*.py" -v
python experiments/metrology_study.py --output /tmp/ct-local-regions --rounds 4 --scales 6,12
python experiments/compare_metrology.py --regions /tmp/ct-local-regions --output /tmp/ct-model-comparison
python experiments/compare_farid3d.py --output /tmp/ct-farid3d
python experiments/benchmark_metrology.py --output /tmp/ct-phantoms
```

В diagnostics сохранены также промежуточные отвергнутые визуальные опыты: локальные пороги инициализации, RSF с другой начальной маской, объединение масок и сохранение только крупнейшей компоненты. Последнее может удалять реальные стенки в коротком блоке и не используется как физическое подтверждение поверхности. Они не являются выбранным автоматическим решением.

Исходные CT_Test, main.cpp и CMake не изменены. Все исходные изображения экспериментов в рабочих каталогах сохранены; копии для GitHub сверены по SHA-256.
